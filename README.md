# Greenhouse Monitor

Інтелектуальна система моніторингу теплиці: покази датчиків температури, вологості й освітленості,
тривоги при виході за норму і вебдашборд у реальному часі.

Навчальний STEM-проєкт з дисципліни «Мультиплатформне програмування» (.NET 10).

## Команда

| Учасник | Зона відповідальності |
|---|---|
| Maksim380 | Ядро: доменна модель, БД, прийом показів, тривоги, теплиці |
| totohalove17 | API: автентифікація і ролі, SignalR, вебдашборд |
| LaBebra | Каркас, CI, симулятор датчиків, Docker, якість коду |

Інструкція з запуску з'явиться разом із кодом.
